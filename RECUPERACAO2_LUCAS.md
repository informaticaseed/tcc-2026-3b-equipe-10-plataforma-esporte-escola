1. O que é uma Issue e para que serve no desenvolvimento de software?
Uma Issue é uma tarefa, problema ou sugestão registrada dentro de um projeto de software. Ela serve para organizar o que precisa ser feito, como corrigir um erro ou adicionar uma nova função. Assim, a equipe consegue acompanhar melhor as atividades e saber quem está responsável por cada uma.
2. O que é um Pull Request e por que ele é importante?
Um Pull Request é uma solicitação para adicionar alterações feitas em um código ao projeto principal. Ele é importante porque permite que outras pessoas revisem o código antes de ele ser incluído definitivamente. Dessa forma, é possível encontrar erros e melhorar o código antes da alteração ser aceita.
3. O que é separação de camadas no código?
Separação de camadas significa organizar o código em partes diferentes, cada uma responsável por uma função específica. O app.py geralmente fica responsável pela aplicação, pelas rotas e pela comunicação com o usuário. Já o repositorio.py fica responsável por acessar e organizar os dados, como informações de um banco de dados. Isso importa porque deixa o código mais organizado, fácil de entender e mais simples de corrigir ou modificar.
